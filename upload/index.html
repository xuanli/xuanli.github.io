Drop the full game video here. It goes up in 100 MB pieces that resume if your connection drops, then gets joined back into the original file for processing. Keep this tab open until every cell turns coral.

If the upload stops (lid closed, Wi-Fi drops), choose the same file again with the same date: it picks up from the last finished piece.

On iPhone: tap the box, then Choose File and pick the video in the Files app. If you pick it from Photo Library, iOS first copies (and may compress) the whole video before the upload can start: that shows its own progress bar, which can sit around 90% for a long time. Save the video to Files first (Share → Save to Files), or upload from a computer.
